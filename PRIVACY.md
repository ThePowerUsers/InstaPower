# Privacy Policy

**InstaPower** is an unofficial, open-source Windows desktop client for Instagram maintained by ThePowerUsers.

## Information handled by InstaPower

InstaPower does not intentionally collect, sell, or send Instagram passwords, authentication tokens, cookies, or other account credentials to ThePowerUsers.

Instagram authentication and Instagram content are handled through Instagram's normal web experience inside the application's dedicated browser session. Session data required to keep you signed in is stored locally by the application.

InstaPower does not include advertising, analytics, or a custom account system.

## External services

When you use InstaPower, your computer communicates with third-party services required by the application:

- **Instagram/Meta:** InstaPower loads Instagram's website and uses Instagram's normal web authentication and content delivery. Instagram/Meta may receive information according to its own privacy policies and terms.
- **GitHub:** InstaPower may check GitHub release information when its update-checking feature is used or scheduled. GitHub handles those requests according to GitHub's privacy practices.

InstaPower does not intentionally send unrelated personal information to these services.

## Local data

The application's dedicated browser profile may contain cookies, cached content, local storage, and other session data created by Instagram. This data is stored on the user's Windows device and is not intentionally uploaded by InstaPower to ThePowerUsers.

Deleting the application does not necessarily delete all local application data unless the user removes that data separately.

## Downloads

Files downloaded through Instagram are saved to a location selected through the normal Windows save flow. InstaPower does not intentionally upload downloaded files to ThePowerUsers.

## Changes to this policy

This policy may be updated when InstaPower's functionality or external services change. The current version is published in the project's GitHub repository.
