# Support

Thanks for using InstaPower.

## Before opening an issue

Please check:

- [Latest release](https://github.com/ThePowerUsers/InstaPower/releases)
- Existing [issues](https://github.com/ThePowerUsers/InstaPower/issues)
- The [documentation in the README](https://github.com/ThePowerUsers/InstaPower#readme)

## Bug reports

For reproducible bugs, please use the [bug report template](https://github.com/ThePowerUsers/InstaPower/issues/new?template=bug_report.md).

Include:

- InstaPower version
- Windows version
- Whether you used the installer or portable build
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant logs or screenshots, with sensitive information removed

**Never include passwords, cookies, session tokens, access tokens, or other private account data.**

## Feature requests

Use the [feature request template](https://github.com/ThePowerUsers/InstaPower/issues/new?template=feature_request.md) and describe the problem the feature would solve.

## Security issues

Do not report security vulnerabilities in a public issue.

Follow the [Security Policy](SECURITY.md) and contact **parstylus@gmail.com** privately.

## Community conduct

Please read the [Code of Conduct](CODE_OF_CONDUCT.md) before participating.

---

If your question is not covered above, open a clearly described issue and provide enough context for others to reproduce or understand the problem.
